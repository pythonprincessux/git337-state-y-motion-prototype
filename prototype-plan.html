State and Motion Prototype Plan

Purpose and state map

Specimen User need States Visual/ motion feedback
Action Help the user recognize the registration action. Default, hover, focus-visible, active Shadow, movement, focus outline, and decorative arrow provide feedback.
Selection Let the user select a community workshop option. Unchecked, focus-visible, checked A visible focus indicator and inset accent bar show interaction and selection.
Disclosure Let the user reveal additional registration details. Closed, open The disclosure reveals confirmation content with a short finite animation.

Effect decisions

Effect 1 and purpose: Box-shadow gives the action control depth and provides visible feedback when it is pressed.

Effect 2 and purpose: An inset box-shadow creates an accent bar that makes the selected choice recognizable without relying on color alone.

Motion decisions

Transition properties and trigger: Transform and box-shadow transition when the action control changes between its default, hover, and active states.

Keyframe purpose and trigger: A short finite animation reveals the confirmation content when the details element is opened.

Reduced-motion alternative: When reduced motion is requested, transitions and animation are removed while the visual state feedback remains available.
